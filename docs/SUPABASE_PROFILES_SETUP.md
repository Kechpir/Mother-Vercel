# Таблица profiles (личный кабинет)

Если при сохранении данных в личном кабинете появляется ошибка **«Не удалось сохранить»** и в Network виден **404** на запрос к `profiles`, значит таблица `profiles` в Supabase ещё не создана.

## Что сделать

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard) и выберите проект.
2. В левом меню: **SQL Editor** → **New query**.
3. Скопируйте содержимое файла **`supabase_profiles.sql`** из корня репозитория и вставьте в редактор.
4. Нажмите **Run** (или Ctrl+Enter).
5. Убедитесь, что выполнение прошло без ошибок (должно быть сообщение вроде «Success. No rows returned»).
6. Обновите страницу личного кабинета и снова нажмите «Сохранить данные».

После этого сохранение профиля должно работать.
