# Личные кабинеты — пошаговая инструкция

Делаем по одному шагу. После каждого шага проверяем, что всё работает, и переходим к следующему.

---

## Шаг 1: Включить авторизацию по email в Supabase

**Что делаем:** включаем в проекте Supabase вход по email и паролю, чтобы пользователи могли регистрироваться и входить.

**Куда заходить:**

1. Откройте **Supabase**: https://supabase.com/dashboard  
2. Выберите **ваш проект** (тот, где уже есть таблицы participants, promo_codes).  
3. В левом меню нажмите **Authentication** (иконка «человечек» / замок).  
4. Откройте вкладку **Providers**.  
5. Найдите **Email**.  
6. Включите переключатель **Enable Email provider** (должен стать активным).  
7. (По желанию) Отключите **Confirm email**, чтобы пользователь мог входить сразу после регистрации без подтверждения письма. Для продакшена потом можно включить обратно.  
8. Нажмите **Save**.

**Проверка:** в разделе Authentication → Providers у Email должно быть состояние «Enabled».

Когда сделаете — напишите «готово» или переходим к Шагу 2 в коде (страницы входа и регистрации).

---

## Шаг 2: Страницы входа и регистрации (следующий)

Будем делать страницы `/login` и `/register` и подключим их к Supabase Auth.

---

## Шаг 3: Страница личного кабинета

Страница `/cabinet`: только для авторизованных, внутри — история покупок (по участникам/оплатам).

---

## Шаг 4: Связь «участник — пользователь»

Добавим в таблицу участников поле `user_id` (или привязку по email), чтобы в кабинете показывать только покупки этого пользователя.
