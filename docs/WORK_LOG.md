# Журнал выполненных работ (лендинг Mother)

Актуальная сводка изменений по лендингу «Энергетические сессии» — блоки, форма, сноска, промокоды, Git.

---

## 1. Блок «Энергетическое выравнивание всех тел и позвоночника»

- **Макет:** текст слева, картинка справа (две колонки на десктопе).
- **Шрифт заголовка:** Cormorant Garamond (`font-hero`), размер уменьшен: `text-xl md:text-2xl lg:text-3xl`, `font-semibold`, без `uppercase`, добавлен `text-balance`.
- **Оформление:** плашка «Исцеляющий цикл», карточка со списком «Когда вы в напряжении», акцентная цитата с `border-l-[#ffa600]`, блок «Период / Формат / Время» внизу текста, у картинки — градиентное свечение и плавающая плашка «Глубокая трансформация на всех уровнях».
- **Анимация:** в `globals.css` добавлена анимация `animate-float` для плашки.

---

## 2. Блок «Этот формат может быть полезен» (симптомы)

- **Ширина:** контейнер `max-w-4xl` → `max-w-6xl`, отступы `md:px-8`.
- **Шрифты:** заголовок `text-xl md:text-2xl`, подзаголовок `text-base md:text-lg`, оранжевые подзаголовки и названия карточек `text-base md:text-lg`, описания `text-sm md:text-base`, итоговый абзац `text-sm md:text-base`.
- **Отступы:** `space-y-10`, `gap-8`, `space-y-2` между заголовком и описанием в карточке.

---

## 3. Уменьшение пустоты между блоками

- Между блоком «Период / Формат / Время» и блоком «Этот формат может быть полезен»:
  - Секция с картинкой: `py-16 md:py-24` → `pt-16 md:pt-24 pb-8 md:pb-12`.
  - Следующий блок: `py-12 md:py-16` → `pt-6 md:pt-8 pb-12 md:pb-16`, внутренний `pt-10` → `pt-4`.

---

## 4. Блок с тремя абзацами про энергетическое выравнивание

- **Ширина:** `max-w-3xl` → `max-w-6xl`, `md:px-8`.
- **Колонки:** первые два абзаца в две колонки на `md+` (`grid grid-cols-1 md:grid-cols-2`), третий абзац на всю ширину (`md:col-span-2`).
- **Шрифт:** `text-base md:text-lg lg:text-xl`, `font-medium` (вместо `font-light`).

---

## 5. Списки «Восстановление оси» и «Работу с энергетическим состоянием»

- Пункты списков: `font-light` → `font-semibold` для лучшей читаемости.

---

## 6. Хедер и кнопка в шапке

- Текст кнопки: **«Оплата»** → **«Забронировать место»**.

---

## 7. Секция регистрации (форма + сноска)

- **Макет:** форма слева, справа блок «Как записаться на курс» (две колонки на `lg+`, на мобильных сноска сверху).
- **Форма:** выравнивание заголовка и подписи по левому краю (`text-left`).
- **Сноска «Как записаться»:**
  - Крупный текст: заголовок `text-lg md:text-xl`, список `text-base md:text-lg`, подпись `text-sm md:text-base`.
  - Оформление: градиент фона `from-amber-50 to-orange-50/50`, рамка `border-[#ffa600]/50`, тень, иконка Info 26px, нумерованный список с отступами, нижняя подпись с `border-t-2 border-[#ffa600]/30`.
- **Размеры:** контейнер `max-w-6xl`, сетка `lg:grid-cols-[1fr_28rem]` — форма занимает оставшееся место, сноска фиксированная 28rem; блок сноски не растягивается по высоте (`items-start`), без пустоты внизу.
- **Форма по высоте уменьшена примерно вдвое:**
  - Карточка: `p-3 md:p-4`, `rounded-2xl`.
  - Шапка: `mb-2 space-y-0.5`, заголовок `text-lg md:text-xl`, подпись короче и `text-[10px]`.
  - Поля: `space-y-1.5`, инпуты `py-2 px-3 pl-10 rounded-lg`.
  - Кнопка и чекбокс: `pt-2 space-y-2`, кнопка `py-2.5 rounded-xl`, блок с чекбоксом `p-2 rounded-lg`.
- **Форма по ширине:** только колонка формы расширена (за счёт `1fr` и `max-w-6xl`), сноска остаётся 28rem — анкету не трогали по контенту, только ширина колонки.
